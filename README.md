# Janela de Fluxo

Sistema web simples para controle e acompanhamento de movimentações financeiras.

## 📌 Sobre o projeto

O **Janela de Fluxo** foi desenvolvido como um projeto prático para aplicar conhecimentos de desenvolvimento web utilizando HTML, CSS e JavaScript.

O sistema permite cadastrar, editar, excluir e filtrar movimentações financeiras, além de calcular automaticamente entradas, despesas e saldo.

Os dados cadastrados são armazenados no navegador utilizando `localStorage`, permitindo que as movimentações continuem disponíveis após atualizar ou fechar a página.

## 🚀 Funcionalidades

* Cadastro de entradas e saídas
* Descrição, valor, data e categoria
* Cálculo automático de entradas, despesas e saldo
* Edição de movimentações
* Exclusão de movimentações
* Filtro por tipo
* Filtro por categoria
* Filtro por período
* Validação dos campos
* Persistência dos dados com `localStorage`

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* LocalStorage

O projeto foi criado com o objetivo de praticar conceitos fundamentais de desenvolvimento web, como manipulação do DOM, eventos, funções, validações, filtros, cálculos e armazenamento de dados no navegador.
